> [!definition]
> A limit is a the value that a function approaches at a point.

> [!example]
> $$\lim_{ x \to 2 }f(x) $$
> This is the limit of the function $f$ as $x$ approaches $2$.
> For example, if $f(x)=x^2$, then this would be $4$.

Sometimes the limit value equals the function value.
But, sometimes the limit value does not equal the function value.

On the flip side, when the function is defined for some 
$x$-value, that doesn't mean that the limit necessarily exists.
The limit as $x$ approaches from the right and the left have to the same for the limit to exist
> [!example]
> ![[Pasted image 20240813093624.png|500]]
> The limit as $x\to3$ does not exist.

When attempting direct substitution on a limit, sometimes you are left with $\frac{0}{0}$. This is called indeterminate form, because it is still indeterminant whether the limit exists. You can try rewriting the limit in an equivalent form, using algebra or [[L'Hôpital's rule]].
