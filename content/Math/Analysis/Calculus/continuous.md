# Math
> [!definition]
> A [[function]] is continuous if at every point the [[value]] of the [[function]] is equal to the [[limit]] at that point. You should be able to trace the graph without having to lift the pencil off the page.
> A point is continuous if
> $$\lim_{ x \to c } f(x)=f(c)$$
