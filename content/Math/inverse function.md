> [!definition]
> Inverse functions reverse each other. For $f$ and $g$ to be inverses:
> $f(g(x))=x$ for all $x$ in the domain of $g$
> $g(f(x))=x$ for all $x$ in the domain of $f$

> [!example]
> If $f$ takes $a$ to $b$, then $f^-1$ takes $b$ to $a$.

Inverting a function reflects it across the line $y=x$, swapping the inputs and outputs

# Invertibility
A [[function]] is only invertible if each input has a unique output. Otherwise, when you try to invert it, some outputs will get mapped back to multiple different outputs.

A quick way to test if a [[function]] is invertible is with the horizontal line test. It works because it proves that each output ($y$) only has one possible input ($x$). 

To make a function invertible, we can limit the [[domain]]. This is common with [[trigonometric function|trigonometric functions]].
