# Chi-squared test for homogeneity
Used when sampling two different groups, you can determine if the [[distribution]] of a variable is the same
$H_{o}:\text{ No difference between groups}$
$H_{a}:\text{ There is a difference between groups}$

# Chi-squared test for independence
Used when sampling one group, you can determine if the [[distribution]]  of two variables is different.
$H_{o}:\text{ No difference between variables}$
$H_{a}:\text{ There is a difference between variables}$
