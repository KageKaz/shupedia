> [!question]
> How would the people be represented under the new [[US Constitution|constitution]]? How can we decide how many representatives each state gets?

^c37d08

# [[Virginia]] Plan
The "big state" plan - bigger states would have more representation, smaller state interests would not prevail
Representatives ought to be apportioned by population.

# [[New Jersey]] Plan
"small state" plan - smaller states would have more power
Representatives ought to be apportioned equally
each state gets one vote.

# Connecticut Compromise
[[House of Representatives]] would be apportioned by population.
Some states have more, small states have less
[[Senate]] apportioned equally (2) for each state.
